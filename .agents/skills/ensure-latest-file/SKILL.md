# Ensure Latest File Version (Global Scope)

เมื่อได้รับคำสั่งให้แก้ไข อ่าน หรือประมวลผลไฟล์ ให้ปฏิบัติตามลำดับขั้นตอนดังต่อไปนี้เสมอ:

### 1. การค้นหาและรวบรวมไฟล์ (Discovery)
- **สแกนแบบครอบคลุมทั้ง Workspace (Recursive Search)**: ค้นหาไฟล์จากทุกโฟลเดอร์และโฟลเดอร์ย่อย ไม่จำกัดเฉพาะ Directory ราก (Root)
- รวบรวมไฟล์ที่มีชื่อฐาน (Base Name) เดียวกัน แต่มีความแตกต่างในด้าน:
  - **เลขเวอร์ชัน**: เช่น `autopage_MKII_ver5_x_x.py`, `autopage_MKII_ver5_1_5LITE.py`
  - **แท็กสถานะ**: เช่น `_current`, `_latest`, `_final`, `_backup`
  - **วันที่/เวลา**: เช่น `data_20260721.json`

---

### 2. เกณฑ์การตัดสินใจเลือกไฟล์ล่าสุด (Decision Tree)

เรียงลำดับความสำคัญในการเลือกไฟล์ดังนี้:

1. **เวอร์ชันงานที่กำลังพัฒนา (Wildcard / Unspecified Version)** **[ความสำคัญสูงสุด]**
   - ไฟล์ที่ระบุเฉพาะ Major Version แล้วใช้ตัวแทนเป็น `x` หรือ `X` (เช่น `5.x.x` หรือ `v5.X`) **ถือเป็นไฟล์ล่าสุดและสำคัญที่สุดใน Major Version นั้นเสมอ**
   - *ตัวอย่าง*: `5.x.x` มี Priority สูงกว่า `5.99.99` เนื่องจาก `x.x` อยู่ในระหว่างการพัฒนาและพร้อมปรับเป็นเวอร์ชันถัดไป (เช่น `5.100.0`)

2. **ลำดับความสำคัญของโฟลเดอร์ (Folder Priority)**
   - หากไฟล์ชื่อเหมือนกันแต่อยู่คนละโฟลเดอร์ ให้ถือว่าโฟลเดอร์ที่มีระบุเลขเวอร์ชันสูงกว่า (เช่น `/autopage_MKII_ver5/...`) บรรจุไฟล์เวอร์ชันล่าสุดไว้

3. **เลขเวอร์ชันแบบเจาะจง (Semantic Versioning)**
   - กรณีไม่มีไฟล์แบบ `x.x` ให้เลือกไฟล์ที่มีเลขเวอร์ชันระบุไว้สูงที่สุดเสมอ (เช่น `5.2.0` > `5.1.9`)

4. **คำกำกับสถานะ (Status Tags)**
   - ให้ความสำคัญกับไฟล์ที่มีคีย์เวิร์ดบ่งบอกสถานะปัจจุบัน เช่น `current`, `latest`, `final`

5. **ตราประทับเวลา (Timestamp / Modified Date)**
   - หากไม่สามารถระบุเวอร์ชันจากชื่อไฟล์ได้ ให้เลือกไฟล์ที่มีวันที่/เวลาแก้ไขล่าสุด (Latest Modified Date) หรือระบุวันที่ในชื่อไฟล์เป็นปัจจุบันที่สุด

---

### 3. ข้อปฏิบัติในการทำงาน (Execution Rules)

- **แจ้ง Path ก่อนเริ่มเสมอ**: ระบุ Path เต็มของไฟล์ที่ระบบเลือกใช้งานให้ผู้ใช้ทราบล่วงหน้าก่อนเริ่มอ่านหรือแก้ไขข้อมูล
- **ข้อห้ามเรื่องไฟล์สำรอง**: ห้ามแตะต้อง หรือแก้ไขไฟล์ที่อยู่ในโฟลเดอร์ประเภท `backup`, `old`, `archive` หรือมีแท็ก `_backup` โดยเด็ดขาด เว้นแต่จะมีคำสั่งเจาะจงจากผู้ใช้
- **การสร้างไฟล์ใหม่**: หากจำเป็นต้องสร้างไฟล์ใหม่ ให้รักษาโครงสร้าง Directory รูปแบบการตั้งชื่อ และโครงสร้างเวอร์ชันเดิมของโปรเจกต์ไว้อย่างเคร่งครัด
