# Ensure Latest File Version (Global Scope)

เมื่อผู้ใช้สั่งให้แก้ไขไฟล์หรืออ่านข้อมูล ให้ปฏิบัติตามขั้นตอนต่อไปนี้:

### 1. การตรวจสอบ (Discovery)
- **สแกนหาทั่วทั้งโปรเจกต์**: ให้ค้นหาไฟล์ที่มีชื่อคล้ายกันจาก **ทุกโฟลเดอร์ย่อย (Recursive Search)** ไม่ใช่เฉพาะใน Root [4]
- รวบรวมไฟล์ที่มีชื่อฐาน (Base name) เดียวกันแต่ต่างกันที่:
  - เลขเวอร์ชัน (เช่น `autopage_MKII_ver5_1_5LITE.py`, `autopage_MKII_ver4_2_1.py`)
  - วันที่/เวลา (เช่น `data_20231027.json`)
  - แท็กสถานะ (เช่น `_backup`, `_final`, `_current`)

### 2. เกณฑ์การตัดสินใจ (Decision Tree) [2]
- **ลำดับความสำคัญของโฟลเดอร์**: หากชื่อไฟล์เหมือนกัน แต่อยู่คนละโฟลเดอร์ ให้สันนิษฐานว่าโฟลเดอร์ที่มีเลขเวอร์ชันสูงกว่า (เช่น `.../autopage_MKII_ver5/...`) บรรจุไฟล์ล่าสุดไว้
- **เลขเวอร์ชัน**: เลือกไฟล์ที่มีตัวเลขสูงที่สุดเสมอ
- **Timestamp**: หากไม่มีเลขเวอร์ชัน ให้ใช้ไฟล์ที่มีวันที่แก้ไขล่าสุด (Latest Modified) หรือระบุวันที่ในชื่อล่าสุด
- **คำกำกับ**: ให้ความสำคัญกับไฟล์ที่มีคำว่า `final`, `latest` หรือ `current`

### 3. การดำเนินการ (Execution) [3]
- แจ้งให้ผู้ใช้ทราบว่ากำลังใช้ไฟล์เวอร์ชันใด (ระบุ Path เต็ม) ก่อนเริ่มดำเนินการ
- ห้ามแก้ไขไฟล์ที่อยู่ในโฟลเดอร์ชื่อ `backup`, `old`, หรือ `archive` เว้นแต่จะสั่งเจาะจง
- หากต้องสร้างไฟล์ใหม่ ให้รักษาโครงสร้างโฟลเดอร์และรูปแบบการตั้งชื่อเดิมไว้
