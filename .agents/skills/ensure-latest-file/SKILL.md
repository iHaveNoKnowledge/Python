# Ensure Latest File Version

เมื่อผู้ใช้สั่งให้แก้ไขไฟล์หรืออ่านข้อมูลในโปรเจกต์ที่มีหลายเวอร์ชัน ให้ปฏิบัติตามขั้นตอนต่อไปนี้:

### 1. การตรวจสอบ (Discovery)
- ก่อนทำการแก้ไข ให้ค้นหาไฟล์ที่มีชื่อคล้ายกันในไดเรกทอรีที่เกี่ยวข้อง
- ตรวจสอบรูปแบบการระบุเวอร์ชัน เช่น:
  - ตัวเลขเวอร์ชัน (e.g., autopage_MKII_ver5_1_5LITE.py`, `autopage_MKII_ver4_2_1.py`)
  - วันที่หรือ Timestamp (e.g., `data_20231027.json`, `data_20231028.json`)
  - คำระบุสถานะ (e.g., `config_backup.yaml`, `config_final.yaml`)

### 2. เกณฑ์การตัดสินใจ (Decision Tree)
- **หากมีตัวเลขเวอร์ชัน**: ให้เลือกไฟล์ที่มีตัวเลขสูงที่สุดเสมอ
- **หากมีวันที่**: ให้เลือกไฟล์ที่มีวันที่ล่าสุด (Most recent date)
- **หากมีการระบุ 'final' หรือ 'current'**: ให้ความสำคัญกับไฟล์เหล่านี้ก่อนไฟล์ที่เป็น 'backup' หรือ 'old'
- **หากไม่แน่ใจ**: ให้แสดงรายชื่อไฟล์ที่พบและถามผู้ใช้ก่อนดำเนินการ

### 3. การดำเนินการ (Execution)
- เมื่อระบุไฟล์ล่าสุดได้แล้ว ให้ใช้ไฟล์นั้นเป็นต้นแบบในการแก้ไขหรืออ่านข้อมูล
- ห้ามแก้ไขไฟล์เวอร์ชันเก่า เว้นแต่จะได้รับคำสั่งเจาะจงจากผู้ใช้
- หากสร้างเวอร์ชันใหม่ (เช่น v3) ให้คงรูปแบบการตั้งชื่อ (Naming Convention) เดิมของโปรเจกต์ไว้
